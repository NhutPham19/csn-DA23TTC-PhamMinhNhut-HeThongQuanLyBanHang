# Đồ án: Xây dựng hệ thống quản lý bán hàng

## 1. Thông tin sinh viên
* **Họ và tên:** Phạm Minh Nhựt

* **Lớp:** DA23TTC
 **Giảng viên hướng dẫn: ThS. Nguyễn Hoàng Duy Thiện

## 2. Giới thiệu đề tài
Đồ án xây dựng phần mềm quản lý bán hàng nhằm giải quyết các vấn đề:
* Quản lý danh sách sản phẩm, tồn kho.
* Quản lý thông tin khách hàng.
* Xử lý đơn hàng và tính toán.
* Xem lịch sử đơn hàng

## 3. Công nghệ sử dụng
* **Ngôn ngữ:** C# (.NET Framework)
* **Giao diện:** Windows Forms (WinForms)
* **Cơ sở dữ liệu:** SQL Server
* **Công cụ:** Visual Studio 2022

## 4. Hướng dẫn cài đặt và chạy
1. **Cấu hình CSDL:**
   * Mở SQL Server Management Studio.
   * Chạy file script `QuanLyBanHang_1.sql`để tạo CSDL.
   * Mở file `KetNoiDuLieu.cs` trong Source Code, sửa lại chuỗi kết nối (Connection String) cho phù hợp với máy.

2. **Chạy chương trình:**
   * Mở file `Solution.sln` bằng Visual Studio.
   * Nhấn `F5` hoặc nút `Start` để chạy ứng dụng.
